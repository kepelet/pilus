Rilis alpha pertama untuk publik. Semua yang ada di bawah adalah isi pilus hari ini; belum ada riwayat versi sebelumnya yang perlu dibandingkan.

## Terhubung ke Luvus

- Klien native (Rust, GPUI, Metal di macOS) yang melukis grid sel dari daemon Luvus tanpa emulator terminal di tengahnya
- Menemukan socket Luvus (sesi default atau bernama lewat `--session`) dan menyalakan daemon kalau belum berjalan
- Luvus dipasang otomatis di peluncuran pertama bila belum ada: versi yang di-pin dan dicek checksum-nya, bukan sembarang rilis terbaru
- Menutup jendela tidak mematikan apa pun; pilus terhubung lagi dan sesi terakhir dibuka kembali
- Mesin SSH tampil di daftar yang sama dengan Local. Koneksi yang putus dicoba lagi sendiri
- Di jaringan lambat: ketikan digambar lebih dulu sebelum daemon membalas, SSH dikompres, dan perubahan ukuran jendela dikumpulkan dulu

## Tampilan

- Sidebar native: Open Workspace, Search, Insights, lalu Pinned Workspaces, Workspaces, Agents (bisa diurutkan dan difilter berdasarkan status), dan Repositories
- Tab ala browser dengan lencana status agent: merah menunggu kamu, oranye bekerja, hijau selesai
- Pane bergaya Comfortable (kartu mengambang) atau Compact (rapat, dengan bingkai); seam bisa diseret, toolbar pane dan zoom opsional
- Appearances (`cmd+,`): skema warna Device, Light, atau Dark; tema; font antarmuka (default Arimo) dan font terminal; Solid atau Translucent; sudut Square, Rounded, atau Custom
- Energy mode: sudut kotak, jendela solid, tanpa animasi
- Command palette (`cmd+shift+p`), menu klik-kanan native macOS, dan item menu bar yang mendaftar agent walau jendela ditutup
- Notifikasi dengan suara dan lencana saat agent menunggu atau selesai; klik memfokuskan agent-nya

## Terminal

- Pilih dan salin teks, `cmd+a` untuk seluruh layar, seleksi tidak melewati batas pane
- `cmd`-klik membuka URL (http, https, mailto) dan path file yang terbaca di layar
- Tempel (`cmd+v`) atau seret gambar ke terminal; yang masuk ke pane adalah path-nya, di mesin lokal maupun remote

## Panel kanan

`cmd+b` membuka panel dengan riwayat Back dan Forward sendiri.

- **Diff**: catatan review yang bisa dikirim ke agent, stage/unstage dan discard per file, tanda Viewed, tampilan pohon, syntax highlight, dan markdown yang dirender dengan tanda perubahan
- **Git**: riwayat commit yang dimuat bertahap, dan isi tiap commit
- **Files**: pohon file dengan tanda perubahan Git, unggah (file dan folder) dan unduh, lipatan folder yang diingat
- **Ports**: port yang didengarkan mesin remote, dan forward-nya ke Mac
- **Browser**: webview WebKit dengan beberapa tab halaman, dan konfirmasi untuk setiap unduhan

## Editor

- Buka file teks langsung dari tab Files: markdown dengan mode Source, Preview, atau berdampingan, dan file lain langsung di source
- Syntax highlight, penanda perubahan Git di gutter, dan diagram mermaid di preview markdown
- Undo per kata, auto-indent, pasangan kurung dan kutip, pintasan baris (pindah, salin, hapus, komentar), dan Go to Line
- Pencarian (`cmd+f`), ganti (`cmd+alt+f`), dan quick open (`cmd+p`)
- Bertanya Save, Don't Save, atau Cancel sebelum menutup file yang belum disimpan, dan memantau perubahan file di disk
- Gambar (png, jpg, gif, webp, bmp, ico, tiff, svg) dibuka sebagai gambar; svg bisa dilihat sebagai source
- Simpan lewat SSH aman: file ditulis ke tempat lain dulu, baru disalin kalau semua byte tiba
- Catatan pada kutipan markdown yang bisa dikirim ke agent sekaligus

## Search dan Insights

- **Search**: cari sesi Claude dan Pi di Mac ini dan mesin SSH. Mati sampai kamu mengizinkannya, dan hanya judul serta metadata yang disimpan
- Halaman sesi dengan Continue dan Fork
- **Insights**: pemakaian token, perkiraan biaya, heatmap aktivitas, dan jam sibuk

## Workspace

- Composer New Agent (`cmd+shift+n`): tulis prompt, pilih agent dan tempat menjalankannya
- Workspace yang di-pin dan yang baru dibuka, bisa diurutkan dengan drag, juga dari item menu bar

## GitHub

- Bagian Repositories lewat `gh` di Mac kamu: tiga repositori, pin yang bisa diurutkan, serta issue, pull request, dan workflow run
- Semua permintaan lewat satu cache; matikan di Settings dan tidak ada permintaan sama sekali

## Remote Access dan iOS

- Remote Access berjalan sebagai service latar yang hidup walau pilus ditutup
- Pairing dengan QR (sekali pakai, 10 menit) dan tiga level akses: View, Control, Operate
- Aplikasi iOS lewat TestFlight (iOS 17 ke atas): daftar agent, layar agent, review diff, sesi terbaru, dan tugas baru
- Notifikasi push saat agent menunggu atau selesai, juga untuk mesin SSH yang tersimpan

## Pembaruan dan keamanan

- Pembaruan OTA dengan channel `stable` dan `preview`. Pemeriksaan otomatis mati secara default
- Setiap unduhan harus bertanda tangan minisign; aplikasi ditandatangani Developer ID dan dinotarisasi
- Tanpa pelacak. Peringatan dan crash dicatat di `~/.pilus/logs/pilus.log`, di mesin kamu saja
- Folder `~/.pilus` hanya bisa dibaca pemiliknya, dan `settings.json` ditulis atomik
- URL dari pane hanya dibuka bila http, https, atau mailto

## Yang perlu diketahui

- Hanya macOS di Apple Silicon. GNU/Linux belum
- Browser bawaan masih basic dan belum bisa dipakai untuk situs non-HTTPS
- Ini alpha. Kalau ada yang rusak, [buat issue](https://github.com/kepelet/pilus/issues)
