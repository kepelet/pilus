Daemon Luvus mengirim tampilan sebagai grid sel bergaya. pilus menggambarnya di jendela GPUI, lalu menambahkan kontrol dan elemen antarmuka native di sekelilingnya.

## Sidebar

Di bagian atas sidebar ada tiga pintasan: **Home**, [**Search**](/features/search-and-insights), dan [**Insights**](/features/search-and-insights). Pintasan ini bisa disembunyikan di Settings → Sidebar. Untuk membuka workspace, pakai ⌘⇧O atau tombol `+` di tab strip.

Di bawahnya ada beberapa bagian:

- **Repositories** menampilkan tiga repo GitHub. Lihat [GitHub](/features/github).
- **Pinned Workspaces** berisi folder lokal dan remote yang kamu pin. Bagian ini muncul setelah kamu pin workspace. Lihat [Workspace yang di-pin](#workspace-yang-di-pin).
- **Workspaces** menampilkan workspace lokal dan SSH dalam satu daftar. Workspace remote diberi ikon server dan nama mesin.
- **Agents** menampilkan agent yang sedang berjalan di semua mesin yang terhubung, dikelompokkan berdasarkan mesin. Tombol jam di header menyaring daftar berdasarkan status. Urutan agent mengikuti status, dengan yang baru berubah muncul lebih dulu.

Klik kanan baris untuk membuka menu konteks. Dari sana kamu bisa mengganti nama, menutup workspace, menampilkan path, pin workspace, membuat worktree, atau menghapus worktree. Path dan nama mesin disembunyikan agar sidebar tetap rapi. Pilih *Show Path* untuk menampilkannya.

### Workspace yang di-pin

Pin mengacu ke folder di sebuah mesin, bukan ke workspace yang sedang terbuka. Klik kanan workspace lalu pilih **Pin this Workspace**. Setelah itu, kamu bisa membukanya dari bagian Pinned Workspaces di sidebar atau dari menu bar.

- Pin tampil sesuai urutan ditambahkan. Kamu juga bisa mengurutkannya sendiri.
- pilus menunggu daemon mengonfirmasi pembukaan sebelum berpindah halaman. Kalau gagal, kamu tetap di tempat dan bisa mencoba lagi.

## Terminal

Pane, tab, dan status bar digambar secara native. Pilih teks dengan pointer, lalu salin dengan `cmd+c`. `cmd+a` memilih seluruh layar. Seleksi tidak melewati batas pane. Klik kanan membuka menu native macOS untuk clipboard, split, fork, ganti nama, dan pindah tab. Fitur lain, seperti membuka path dengan `cmd`-klik atau menempel gambar, dijelaskan di [Terminal](/features/terminal).

Tab berfungsi seperti tab browser. Ikon di samping judul menunjukkan jenis tab. Lencana di sudutnya menunjukkan status agent yang sedang difokuskan: merah berarti menunggu, oranye bekerja, dan hijau selesai. Klik kanan tab untuk mengganti nama atau menutupnya. Seret tab untuk mengurutkan ulang.

### Pane

Di Appearances, **Pane style** punya dua pilihan:

| Gaya | Tampilan |
| --- | --- |
| Compact (default) | Pane rapat dengan bingkai tipis di tiap pane. |
| Comfortable | Pane tampil sebagai kartu dengan jarak di antaranya. |

## Panel kanan

Tekan `cmd+b` untuk membuka panel di samping terminal. **Diff**, **Git**, dan **Files** ada di strip tab. **Ports** dan **Browser** dibuka dari tombol di header.

| Tab | Isi |
| --- | --- |
| Diff | Review perubahan Git di workspace, catatan review, serta stage dan discard per file. |
| [Git](/features/git) | Riwayat commit dan perubahan di tiap commit. |
| [Files](/features/file-explorer) | File tree workspace dan [editor](/features/editor). |
| [Ports](/features/port-forwarder) | Port yang sedang didengarkan mesin aktif. |
| [Browser](/features/in-app-browser) | Webview dengan tab halaman. |

Panel punya riwayat navigasinya sendiri. Tombol Back dan Forward di strip bekerja seperti di browser. Misalnya, buka file dari Diff lalu tekan Back untuk kembali ke pohon file. Kamu bisa menyeret tepi panel untuk mengubah lebarnya. Saat mengedit file, panel melebar sementara.

## Command palette

Tekan `cmd+shift+p` lalu ketik untuk menyaring perintah. Tekan Enter untuk menjalankannya. Hampir semua perintah menu ada di sini, termasuk beberapa yang hanya tersedia lewat palette.

## Notifikasi

Saat agent menunggu jawabanmu atau menyelesaikan giliran, pilus menampilkan toast di jendela. Kalau pilus tertutup aplikasi lain atau tidak punya jendela terbuka, macOS menampilkan notifikasi dengan suara dan lencana. Klik notifikasi untuk memfokuskan agent.

Menu bar macOS juga menampilkan agent dan workspace yang di-pin, bahkan saat jendela pilus ditutup. Kamu bisa mematikannya lewat **Settings -> Menu Bar**.

## Tampilan

Tekan `cmd+,` untuk membuka **Appearances**:

- **Color scheme**: Device (mengikuti pengaturan Mac), Light, atau Dark. Tema terang dan gelap bisa dipilih terpisah. Tema bawaan adalah `rose-pine-dawn` dan `noir`.
- **Fonts**: atur font antarmuka (bawaan Arimo) dan font terminal (bawaan Ioskeley Mono), beserta ukurannya.
- **Transparency**: pilih Solid, Translucent, atau Custom untuk mengatur opacity dan blur.
- **Corners**: pilih Square, Rounded, atau Custom, dengan radius sampai 16 px.
- **Terminal**: atur kursor berkedip (mati secara default supaya jendela idle tetap diam) dan jarak atas terminal.

### Energy mode

Pilih **Turn On Energy Mode** di command palette untuk membuat sudut jendela persegi, menghilangkan transparansi, dan mematikan animasi. Pengaturan Appearances tidak berubah, jadi tampilan pilihanmu kembali saat Energy Mode dimatikan. Berguna saat memakai baterai atau ketika Mac sedang sibuk. Atau, sekali lagi, apa adik-adik? Ya, ketika sedang WFC dan lupa membawa charger.

Pertimbangkan membawa charger jika berencana WFC, folks!
