pilus adalah klien desktop untuk [Luvus](https://luvus.dev), terminal multiplexer untuk mengelola coding agent. Luvus tetap berjalan di latar belakang saat jendelanya ditutup. pilus bisa menyambung lagi kapan saja dan menampilkan workspace, pane, tab, serta status agent tanpa terminal emulator tambahan.

Nama pilus diambil dari tiga teknologi yang dipakainya:

- **Pi**, agent harness untuk pilus ("si pilus", atau sipil, WIP)
- **Iroh**, network stack untuk koneksi P2P
- **Luvus**, terminal multiplexer

## Yang bisa dilakukan

- Menggunakan Luvus lewat antarmuka grafis berbasis GPUI
- Melihat workspace dan agent dari mesin lokal maupun SSH dalam satu daftar
- Meninjau diff, mengirim catatan ke agent, melihat riwayat Git, dan membuka GitHub
- Menelusuri file, mengeditnya, meneruskan port, dan membuka halaman di browser bawaan
- Mencari sesi agent dan melihat pemakaian token lewat Search dan Insights
- Memantau agent dan membalasnya dari aplikasi iOS

## Prinsip

- Ringan, dengan penggunaan sumber daya yang rendah
- Cepat, dengan dukungan Metal di macOS
- Tetap ramping, dengan MacBook Neo sebagai patokan

## Platform

Platform utama pilus adalah macOS di Apple Silicon.

GNU/Linux belum memiliki rilis.

Dan aplikasi iOS dan iPadOS baru tersedia melalui internal TestFlight.
