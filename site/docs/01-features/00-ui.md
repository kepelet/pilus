Daemon Luvus mengirim seluruh permukaannya sebagai grid sel bergaya. pilus melukis grid itu di
jendela GPUI, lalu menutupi bagian chrome-nya dengan elemen native.

## Sidebar

- **Repositories**: tiga repositori GitHub, lihat [GitHub](/features/github).
- **Workspaces**: workspace lokal dan SSH dalam satu daftar. Baris remote memakai ikon server
  dan nama mesin.
- **Agents**: agent yang hidup dari setiap mesin yang terhubung, dikelompokkan per mesin.

Klik kanan sebuah baris untuk menu konteks: ganti nama, tutup, tampilkan path, salin path dan branch,
worktree baru, dan hapus worktree.

## Terminal

Pane, tab, dan status bar digambar native. Pilih teks dengan pointer dan salin dengan `⌘C`;
`⌘A` memilih seluruh layar. Klik kanan membuka menu bergaya pilus (clipboard, split, fork,
ganti nama, pindah ke tab). Pane bisa memakai bingkai bulat milik pilus, dengan atau tanpa jarak,
dan seam antar-pane bisa diseret untuk mengubah ukuran.

## Panel kanan

`⌘B` membuka kolom di samping terminal dengan empat tab:

| Tab | Isi |
| --- | --- |
| Diff | Review perubahan Git workspace, catatan review, dan staging per file. |
| [Git](/features/git) | Riwayat commit dan isi tiap commit. |
| [Files](/features/file-explorer) | Pohon file workspace. |
| [Ports](/features/port-forwarder) | Port yang sedang didengarkan mesin aktif. |

Browser ada di kolom yang sama: [In-app browser](/features/in-app-browser).

## Halaman

Mission Control, Tasks, Orchestration, dan Automations adalah halaman native untuk model data
daemon: agent hidup, antrean tugas (daftar atau kanvas berpanah), dan jadwal. Halaman ini hanya
menampilkan dan mengirim perintah; daemon tetap pemilik datanya.

## Command palette

`cmd + shift + p` membuka palette: ketik untuk menyaring perintah, Enter untuk menjalankan.

## Notifikasi

Saat agent mulai menunggu jawabanmu atau selesai, pilus menampilkan toast di dalam jendela. Kalau
pilus di belakang aplikasi lain atau tanpa jendela, notifikasi native dengan suara dan lencana
muncul, dan klik pada notifikasi memfokuskan agent-nya. Item di menu bar macOS menampilkan daftar
agent yang tetap hidup walau jendela ditutup.

## Tampilan

Di **Appearances** kamu memilih tema Luvus (atau satu untuk mode terang dan satu untuk mode gelap),
font antarmuka (default Arimo) dan font terminal, ukuran teks, opasitas, blur, dan radius sudut.
Blur memakai `NSVisualEffectView` milik pilus, bukan blur bawaan GPUI.
