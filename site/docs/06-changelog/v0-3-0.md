GitHub di sidebar dan notifikasi yang bisa dilihat dari jauh.

- Bagian Repositories di sidebar lewat `gh`: tiga repositori, pin yang bisa diurutkan, serta issue, pull request, dan workflow run
- Notifikasi dengan suara dan lencana saat agent menunggu atau selesai, termasuk saat tanpa jendela; klik memfokuskan agent-nya
- Unduh dari tab Files, unggah folder, dan petunjuk tempat file mendarat
- Zoom pane yang fokus dari toolbar
- Pemilih sesi pindah ke header
- Panel Quick Actions terbuka sebagai flyout
