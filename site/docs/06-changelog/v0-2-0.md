Panel kanan, aplikasi iOS, dan jalur rilis yang bertanda tangan.

- Panel kanan: Diff dengan catatan review dan staging per file, Git, Files, Ports, dan Browser
- Aplikasi iOS lewat Remote Access: pairing QR, review diff, dan notifikasi saat agent menunggu
- Port forwarder untuk mesin SSH
- Halaman native Mission Control, Tasks, Orchestration (kanvas), dan Automations
- Item menu bar yang daftar agent-nya bertahan setelah jendela atau aplikasi ditutup
- Pane dengan bingkai bulat, layout flush, dan seam yang bisa diseret
- Sesi dan mesin terakhir dibuka kembali saat peluncuran
- DMG seret-ke-Applications; pembaruan harus bertanda tangan minisign
