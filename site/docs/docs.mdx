pilus adalah klien desktop native untuk [Luvus](/blog/luvus), terminal multiplexer yang menjadi
mission control untuk coding agent. Luvus tetap berjalan di latar belakang walaupun kamu menutup
jendelanya; pilus tinggal terhubung kembali dan menampilkan workspace, pane, tab, dan status agent
apa adanya, tanpa terminal emulator tambahan.

Namanya diambil dari tiga teknologi yang membentuknya:

- **Pi durable**, agent harness untuk pilus
- **Iroh**, network stack untuk koneksi P2P
- **Luvus**, terminal multiplexer

## Yang kamu dapatkan

- Antarmuka grafis untuk Luvus, dibangun di atas GPUI
- Workspace dan agent dari mesin lokal maupun SSH dalam satu daftar
- In-app browser, port forwarder, integrasi Git, dan file explorer
- Aplikasi iOS untuk mengontrol pilus dari perangkat mobile

## Prinsip

- Low footprint
- Performant, memakai Metal di macOS
- Lean, dengan MacBook Neo sebagai baseline

## Platform

macOS adalah platform utama. GNU/Linux belum ditentukan, dan iOS serta iPadOS tersedia lewat
TestFlight.
