Rilis alpha kedua pilus! Di pembaruan ini, sebagian besar ada di in-app browser nya pilus.

## Memperkenalkan: `pilus ctl`

- `pilus ctl` mengirim perintah ke jendela pilus yang sedang terbuka lewat `~/.pilus/pilus.sock`. Kamu bisa membuka panel kanan pada tab tertentu, pindah tab, meminta `state`, atau menjalankan `ping`.
- `pilus ctl ports list` dan `ports forward` bekerja lewat tab Ports. Perintah forward hanya berhasil untuk port yang sedang didengarkan mesin, sama seperti tombol Forward.
- Agent yang berjalan di mesin SSH juga bisa mengendalikan jendela. Centang **Let agents on `<machine>` drive this window** di tab Ports. pilus menjalankan `ssh -R` agar socket tersedia di mesin itu pada `~/.pilus/pilus-remote.sock`. Fitur ini mati di semua mesin sampai kamu mengaktifkannya.

Semoga berguna untuk yang menjalankan agent di remote machine!

## Browser untuk agent

- Agent bisa membuka tab sendiri dengan `pilus ctl browser open`. Tab terbuka dalam mode incognito, tanpa sesi loginmu, dan bisa mengakses alamat HTTP atau HTTPS mana pun.
- Tab agent ditandai dengan garis putus-putus dan chip di strip tab.
- Agent bisa membaca dan berinteraksi dengan halaman lewat `snapshot`, `text`, `html`, `click`, `fill`, `press`, `scroll`, `drag`, `wait`, `eval`, `network`, dan `console`.
- `drag` bisa memindahkan elemen ke elemen lain, menggesernya beberapa piksel (`--by`), atau menyeretnya dari satu titik di viewport (`--at`). Berguna untuk slider, daftar yang bisa diurutkan, dan canvas.
- Kursor virtual bergerak ke target dan menampilkan lingkaran saat diklik. Kursor tetap terlihat selama agent mengendalikan tab.
- Saat agent bekerja, tab terkunci. Lapisan transparan menahan klik, scroll, dan ketikan, sementara bingkai beraksen menandai halaman yang sedang dikendalikan. Tekan **Take over** di pojok kanan atas untuk mengambil alih.
- Agent tidak bisa menyentuh tab yang sedang kamu pakai. Dengan `browser request`, agent hanya bisa meminta akses; kamu yang memilih Allow atau Deny. Tab yang dipinjamkan kembali ke kendalimu saat agent melepasnya, kamu menekan **Take over**, atau tab ditutup.
- `browser viewport` mengatur ukuran halaman ke `responsive`, `16:10`, `4:3`, `mobile`, `tablet`, atau ukuran khusus `LEBARxTINGGI`.

## Browser

- Tombol tiga titik di address bar membuka menu **Notes**, **Viewport**, **Open in Default Browser**, dan **Copy URL**.
- **Notes** bisa dipakai untuk menandai elemen halaman. Pilih elemen dan tulis catatan; catatan itu muncul sebagai lencana bernomor dan tersimpan di tray. **Copy notes** menyalin semua catatan agar bisa ditempel ke agent.
- Pengaturan **Viewport** berlaku per tab. Pilih Responsive, 16:10 (1280×800), 4:3 (1024×768), Mobile, atau Tablet. Halaman ditata sesuai ukuran viewport, lalu diperkecil agar muat di kolom. Media query pun mengikuti ukuran yang dipilih.
- Halaman tetap terlihat saat panel kanan diseret. Halaman hanya disembunyikan ketika panel sedang bergerak.

## Sidebar

- **Pinned Workspaces** pindah dari isi sidebar ke tombol folder di header. Daftarnya bisa diurutkan dengan drag, diurutkan A–Z, atau di-unpin lewat tombol di tiap baris. Saat sidebar diciutkan, tombol ini pindah ke tab strip.
- `cmd+o` membuka palette workspace yang di-pin. Ketik untuk mencari, lalu tekan Enter untuk membuka workspace.
- `cmd+shift+s` membuka palette untuk berpindah sesi Luvus. Tombol sesi juga kini ada di samping tab pertama.
- Baris **Open Workspace** dihapus. Gunakan `cmd+shift+o` atau tombol `+`.
- Pengaturan **Quick links**, yang aktif secara default, bisa menampilkan atau menyembunyikan Home, Search, dan Insights.
- Gaya pane **Compact** menampilkan daftar Workspaces tanpa rel pohon. Nama mesin lebih tebal, baris mesin lebih redup, dan pill baris melebar sampai tepi panel.
- Header Agents kini memakai ikon filter, dan tombol `+` berada di tengah header bagian.
- Bagian Sipil dan GitHub tidak lagi punya jarak kosong di atas saat berada di urutan pertama.

## Git

- Header Changes dan History kini menampilkan branch dalam chip berbingkai. Label jumlah file yang berubah dan stash sudah dihapus.

## Yang perlu diketahui

- Agent yang mengendalikan Browser mengunci tab sesuai aturan yang kamu pilih. Tidak ada pekerjaan yang berjalan dengan timer. Kalau agent lupa melepas tab, tekan **Take over** atau tutup tab untuk mengambilnya kembali.
- Untuk menjalankan `pilus ctl` dari mesin remote, binary `pilus` harus ada di mesin itu. Binary ini hanya dipakai sebagai klien `ctl`; pilus tidak memasang apa pun di mesin remote.
- Belum ada alias untuk `pilus`, jadi, kemungkinan, gunakan `/Applications/pilus.app/Contents/MacOS/pilus ctl` untuk mengakses `pilus` via command line
