Versi pertama: pilus terhubung ke Luvus dan melukis permukaannya di jendela native.

- Menemukan socket klien Luvus (sesi default atau bernama) dan menyalakan daemon bila belum berjalan
- Handshake berversi, lalu grid penuh dan diff sparse dilukis lewat GPUI
- Sidebar, tab, dan status bar native menggantikan chrome daemon
- Workspace dan agent dari mesin lokal dan SSH dalam satu daftar
- Pembaruan OTA dari feed rilis
